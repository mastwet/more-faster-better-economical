# 多 · 快 · 好 · 省

一个面向 AI Agent 的工程原则 Skill，用于项目规则制定、架构设计、开发规划和代码审查。

## 核心原则

- **多（More）** — Less is more。用简单、可组合的架构，让用户凭创造力塑造能力。
- **快（Fast）** — 以省为前提，注重架构性能与运行速度，减少层次和开销，像羽毛一样轻快。
- **好（Good）** — 精益开发与精益项目管理。顶层设计者和 Agent 监管者负责明确架构、控制范围、减少返工，并交付可验证的结果。
- **省（Frugal）** — 聚焦用户价值，禁止擅自添加需求外功能，以尽可能少的总代码量、复杂度、依赖和流程完成需求。

取舍时，先守住正确性和产品契约，再选择总成本最低的方案。减少 LOC 的同时，保留可读性与必要验证。

## 使用

将本仓库放入你的 Agent 支持的 Skill 目录，或让 Agent 读取 [SKILL.md](SKILL.md)，例如：

> 请按照多快好省原则，审查这个项目的架构，并提出最小必要改进。

可独立使用，也可与 **Supermanagement**（规划）和 **Superpowers**（执行）配合，不强制引入额外流程。
